# GameToyProtocolBridge (GTPB)

**Читать на других языках:** [简体中文](README.zh-CN.md) · [English](README.md) · [日本語](README.ja-JP.md) · [한국어](README.ko-KR.md) · [Deutsch](README.de-DE.md) · [Français](README.fr-FR.md) · [Русский](README.ru-RU.md) · [Español](README.es-ES.md) · [Português (Brasil)](README.pt-BR.md)

GameToyProtocolBridge (GTPB) — это **мост протокола Buttplug v3**, который позволяет играм (например, MultiFunPlayer) управлять аппаратными устройствами через WebSocket.

**Поток данных:**

```
Игра (MultiFunPlayer и др.) → GTPB (ws://127.0.0.1:12345, Buttplug v3)
  → разбор / сопоставление / преобразование → Intiface Central → игрушечное устройство
```

## Возможности

- **Двойной прокси WebSocket + TCP** — двусторонняя связь между играми и Intiface Central
- **Сопоставление каналов** — гибкая настройка соответствия игровых каналов аппаратным приводам
- **Режим шести осей OSR6** — сопоставляет шестиосевые команды OSR6 с реальным устройством (L0 основной ход / L1 вперёд-назад / L2 влево-вправо / R0 кручение / R1 крен / R2 тангаж)
- **Аварийная остановка** — перехват всех команд устройств одним кликом, отправка StopAllDevices
- **Многоязычность** — 简体中文、English、日本語、Deutsch、Français、Русский、Español、Português (Brasil)、한국어
- **Управление профилями** — загрузка, сохранение, сохранить как для разных конфигураций подключения и схем сопоставления каналов
- **Обнаружение конфликта портов** — автоматическая проверка конфликта игрового и внутреннего портов при запуске
- **Система журналирования** — системный журнал, журнал протокола GameRx/Tx, журнал захвата

## Быстрый старт

### Предварительные требования

1. Установите и запустите [Intiface Central](https://intiface.com/central/)
2. Убедитесь, что ваше игрушечное устройство подключено через Intiface Central

### Запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Режим GUI
python main.py

# Режим без интерфейса
python main.py --headless

# Указание профиля и параметров
python main.py --profile profiles/my.json --listen 0.0.0.0 --ws-port 12345 --backend ws://127.0.0.1:12346
```

### Сборка в EXE

```bash
pip install pyinstaller
pyinstaller gtpb.spec
```

## Настройка портов (важно)

**Два порта должны отличаться!**

| Порт | По умолчанию | Описание |
|------|-------------|----------|
| Порт WebSocket | 12345 | Порт, через который игры подключаются к GTPB (соглашение на стороне игры, обычно не меняется) |
| Внутренний Intiface | ws://127.0.0.1:12346 | Порт, через который GTPB подключается к Intiface Central |

Если они совпадают, поток данных попадает в бесконечный цикл. GTPB автоматически обнаруживает и предупреждает при запуске.

Решение: Intiface Central → Settings → Server → изменить Listening Port (рекомендуется 12346), затем соответствующим образом обновить «Внутренний Intiface» в GTPB.

## Структура файлов

```
gtpb-python/
├── gtpb/                    # Основные модули
│   ├── __init__.py
│   ├── backend.py           # Подключение к внутреннему Intiface
│   ├── buttplug.py          # Разбор протокола Buttplug v3
│   ├── config.py            # Загрузка конфигурации (INI + JSON-профиль)
│   ├── gui.py               # Графический интерфейс Tkinter
│   ├── i18n.py              # Многоязычность
│   ├── logs.py              # Менеджер журналов
│   ├── mapping.py           # Движок сопоставления каналов
│   ├── models.py            # Модели данных
│   ├── proxy.py             # Ядро мостового сервиса
│   ├── safety.py            # Механизм безопасности (аварийная остановка)
│   └── transform.py         # Преобразование значений
├── profiles/default.json    # Профиль по умолчанию
├── tests/                   # Модульные тесты
├── tools/                   # Инструменты для разработки
├── configsetting.ini        # Заводская конфигурация (не изменяйте)
├── main.py                  # Точка входа программы
└── requirements.txt         # Зависимости Python
```

## Файлы времени выполнения

| Файл | Описание |
|------|----------|
| `profiles/*.json` | Ваши профили (настройки подключения + сопоставление каналов) |
| `.gtpb_settings` | Внутреннее состояние (язык, путь последнего загруженного профиля) |
| `gtpb.log` | Журнал с прокруткой (лимит 10 КБ, автоматически удаляет старые записи) |

## Аргументы командной строки

| Аргумент | Описание |
|----------|----------|
| `--headless` | Режим без интерфейса |
| `--profile <путь>` | Указать файл профиля |
| `--listen <адрес>` | Адрес прослушивания (переопределяет профиль) |
| `--ws-port <порт>` | Порт WebSocket (переопределяет профиль) |
| `--tcp-port <порт>` | Порт TCP (переопределяет профиль) |
| `--backend <url>` | Адрес внутреннего Intiface (переопределяет профиль) |
